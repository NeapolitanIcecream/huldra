# Security policy

## Supported versions

Security fixes are applied to the latest released version.

## Report a vulnerability

Use GitHub's private vulnerability reporting flow:

<https://github.com/NeapolitanIcecream/huldra/security/advisories/new>

Include the affected version, reproduction details, expected impact, and any
suggested mitigation. Do not disclose exploit details in a public issue.

If private reporting is unavailable, open a minimal issue asking the
maintainer to enable a private channel; do not include sensitive details.
